# Customer Orders SQL Analysis

## Project Overview
This project demonstrates SQL skills through the creation and analysis of a relational customer-order database.

The database contains customers, products, orders, and individual order items. SQL queries are used to explore customer spending, product revenue, and purchasing activity.

## Database Structure

The project contains four related tables:

- Customers
- Products
- Orders
- Order_Items

Primary and foreign keys are used to create relationships between the tables.

## SQL Skills Demonstrated

- CREATE TABLE
- Primary Keys
- Foreign Keys
- INSERT INTO
- SELECT
- WHERE
- INNER JOIN
- LEFT JOIN
- GROUP BY
- SUM()
- Calculated fields
- ORDER BY

## Analysis Performed

The project answers questions such as:

- What products did each customer order?
- How much has each customer spent?
- Which customers have not placed an order?
- Which products generated the most revenue?

## Key Findings

- Emma Smith had the highest total spending at $1,730.
- Laptop generated the highest product revenue at $1,200.
- Desk and Monitor were the highest-selling products by units, with 2 units each.
- Noah Wilson had no recorded orders.
